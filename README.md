# DAEG.DEV — Portfolio Hub

個人事業主・ひとり社長のためのAI実装パートナー「**ダエグ先生**」のポートフォリオハブサイト。

3つの事業 — **Uploom**（AIスクール）／**AI Consult**（AI開発・研修）／**CLASS**（教員向けAIプラットフォーム） — を1つに集約し、訪問者を最適なサービスへ振り分ける装置として機能する。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 9セクション構成のメインページ |
| `assets/style.css` | デザイン（白×深緑モダン） |
| `assets/script.js` | インタラクション（カウントアップ・3Dティルト・Now Working切替） |
| `assets/logo.svg` | ロゴ（純ワードマーク＋ドット） |
| `assets/favicon.svg` | ブラウザタブ用ファビコン |
| `assets/apple-touch-icon.png` | iOSホーム追加用 |
| `assets/images/` | ヒーロー背景・サービスビジュアル・OG画像 |
| `CNAME` | カスタムドメイン（daeg.dev） |
| `sitemap.xml` / `robots.txt` | SEO関連 |

## 公開

GitHub Pages で公開。カスタムドメインは `daeg.dev`。
